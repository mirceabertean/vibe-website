# Start Session

Rulează următorii pași la începutul sesiunii de lucru:

1. **Citește ROADMAP.md** (dacă există) pentru TODO-uri active
2. **Citește CLAUDE.md** din proiect pentru context specific
3. **Rulează `git status`** pentru a vedea modificările nesalvate
4. **Rulează `git log --oneline -5`** pentru ultimele 5 commits
5. **Afișează un rezumat formatat** cu:
   - Ultimele modificări (din git log)
   - TODO-uri active (din ROADMAP.md dacă există)
   - Modificări nesalvate (din git status)
6. **Întreabă** "Cu ce continuăm azi?" și așteaptă direcția utilizatorului
